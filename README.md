# CallMy Pay VPN

This is the independent binary-only repository for the CallMy Pay VPN Android channel.

- Android package: `ru.callmy.payvpn`
- Business API: `https://callmyh.ru/wp-json/callmy-pay/v1` (HTTPS 443)
- Release tags: `v<version>-pay-vpn`
- Repository: `dictovod/payVPN`
- Current release: `v2.0.4-pay-vpn`

Every release is compiled and verified for all supported ABIs. The public GitHub Release intentionally contains only the most common `release-arm64-v8a.apk`; the other compiled variants stay on the private builder. Android and server source code, keystores, local build settings, API keys and server secrets are not published in this repository.
